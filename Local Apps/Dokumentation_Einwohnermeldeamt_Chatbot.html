1 Systemübersicht

AttributWert
ProduktnameDigitaler Bürgerassistent – Einwohnermeldeamt
DateitypEigenständige HTML-Webanwendung (Single-Page Application)
Dateinameeinwohnermeldeamt-chatbot.html
SpracheDeutsch
ZielgruppeBürgerinnen und Bürger mit Fragen zum deutschen Meldewesen
Version1.0

Die Anwendung ist ein KI-gestützter Chatbot für das Einwohnermeldeamt, der Bürgerinnen und Bürgern bei Fragen rund um das Meldewesen hilft. Sie läuft vollständig im Browser, benötigt keine Serverinstallation und kommuniziert direkt mit der Anthropic Claude API.

2.2 Architekturprinzip

Die Anwendung folgt dem Prinzip einer Zero-Dependency Single-Page Application: Der gesamte Quellcode (HTML, CSS, JavaScript) ist in einer einzigen Datei zusammengefasst. Es werden keine externen Bibliotheken, Frameworks oder CDN-Ressourcen geladen. Die Kommunikation mit der KI erfolgt direkt vom Browser aus über die Anthropic REST API.

2.3 Datenfluss

1
Nutzer gibt Text ein oder wählt einen Themen-Chip
2
Nachricht wird dem lokalen Gesprächsverlauf (history[]) hinzugefügt
3
POST-Anfrage an https://api.anthropic.com/v1/messages mit stream: true
4
Server-Sent Events werden zeilenweise gelesen und dekodiert
5
Antworttext wird live in der Chat-Oberfläche dargestellt (Streaming-Cursor ▌)
6
Vollständige Antwort wird dem Gesprächsverlauf hinzugefügt

4.3 Gesprächsverlauf

Alle Nachrichten werden sitzungslokal im JavaScript-Array history[] gespeichert und bei jeder Anfrage vollständig an die API übermittelt. Dadurch ist kontextuelles Gesprächsgedächtnis innerhalb einer Browsersitzung möglich. Bei Seitenneuladen wird der Verlauf gelöscht.

5 Sicherheit und Datenschutz

5.1 API-Schlüssel-Handling

  • Der Schlüssel wird niemals in localStorage, sessionStorage, Cookies oder URL-Parametern gespeichert.
  • Speicherung ausschließlich in einer JavaScript-Variablen im flüchtigen Arbeitsspeicher.
  • Bei Seitenneuladen ist erneute Eingabe erforderlich.
  • Übertragung erfolgt ausschließlich über HTTPS an api.anthropic.com.

5.2 Gesprächsdaten

  • Nachrichten verlassen den Browser nur als verschlüsselte HTTPS-Anfragen an Anthropic.
  • Kein eigener Server — keine serverseitige Protokollierung durch die Anwendung selbst.
  • Anthropic verarbeitet die Daten gemäß seiner aktuellen Datenschutzrichtlinie.

5.3 XSS-Schutz

Nutzereingaben werden vor der Darstellung HTML-escaped (&, <, > werden ersetzt). Nur Bot-Antworten werden als HTML gerendert — nach kontrollierter Konvertierung durch den eingebetteten Markdown-Renderer.

5.4 Pflichtlicher Browser-Header

Die API-Anfrage enthält den Header anthropic-dangerous-direct-browser-access: true, der von Anthropic für direkte Browser-zu-API-Kommunikation vorgeschrieben ist und explizit bestätigt, dass der Aufrufer sich der Sicherheitsimplikationen bewusst ist.

9 Inbetriebnahme

9.1 Direktstart (empfohlen)

1
Datei einwohnermeldeamt-chatbot.html im Browser öffnen (Doppelklick oder Drag & Drop)
2
Anthropic API-Schlüssel in das Eingabefeld eingeben
3
Schaltfläche „Assistent starten" klicken
4
Der Chat-Assistent ist sofort betriebsbereit

9.2 Über lokalen HTTP-Server (optional)

Falls der Browser den direkten Dateizugriff einschränkt, kann ein lokaler Server genutzt werden:

Python 3 (empfohlen):

python -m http.server 8080
→ http://localhost:8080/einwohnermeldeamt-chatbot.html

Node.js:

npx http-server . -p 8080 --cors
→ http://localhost:8080/einwohnermeldeamt-chatbot.html

Konfigurationen für beide Varianten sind in .claude/launch.json hinterlegt.
